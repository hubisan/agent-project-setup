# Plan project

1. Reuse the discovered purpose and desired result; supply missing parts only where they block action.
2. Capture ideas without prematurely turning every thought into a task.
3. Organize work into coherent parts, dependencies, decisions and next actions. Use the project's existing task authority.
4. Identify at least one physically executable **next action**; distinguish blocked/waiting work, someday ideas, and firm calendar commitments.
5. Keep plans proportional to the situation. Offer a review cadence when real dependencies exist; no invented deadlines.
6. Persist a requested plan without duplicating tasks in other trackers.

**Done:** The user sees what to do next, what is waiting and why, without a bloated task list.
