# Review project

1. Consult the authoritative status and task source, not stale conversation memory.
2. Start with current NEXT actions and genuinely actionable WAIT follow-ups; suppress snoozed items until review is due.
3. At intervals appropriate to the user's workflow inspect INBOX, unresolved captures, stuck items and SOMEDAY without flooding the daily view.
4. Check whether new evidence changes the chosen solution or the project's next useful action.
5. Propose focused adjustments. Write status changes only under applicable permission rules.
6. Report a concise project pulse, blockers and one or two next actions.

**Done:** The user can act without scanning the entire backlog. If access to source data is missing, describe the limitation.
