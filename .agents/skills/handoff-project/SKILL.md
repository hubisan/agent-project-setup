# Handoff project

1. Identify whether this is a session handoff or an **ownership transfer** from a wiki into a new project.
2. Gather authoritative goals, current state, verified decisions, research, options, sources, feature ideas, risks, open questions and next actions. Label guesses.
3. Trace every major claim to its existing project source. Preserve stable links and prefer Org file-context CUSTOM_ID links for new heading references.
4. Prepare a compact, portable handoff in the target's working format. Identify original and target authorities, without prematurely changing either.
5. For repository extraction, verify copied content and link integrity first. Only after user approval mark the destination authoritative and add a dated pointer to the original wiki.
6. If the target is not writable, label the handoff exported or proposed, not saved.

**Done:** Another agent can continue from files without a full chat history; no two undocumented competing sources of truth remain.
