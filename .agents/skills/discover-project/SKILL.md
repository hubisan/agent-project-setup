# Discover project

1. Read only the relevant existing notes, goals and decisions. Do not restart an already documented investigation.
2. Identify the underlying purpose, desired outcome, constraints and involved people or systems.
3. Separate evidence from hypotheses, ideas and open questions. Preserve links and original sources.
4. Suggest the smallest next experiment, research question or conversation that reduces material uncertainty; recommend a direction and why.
5. Capture approved findings in the authoritative project document only when write permission and target location are clear.

**Done:** The user can state the intended outcome and the next useful learning action, even when the final solution form remains open.
