# Shape project

1. Retrieve the current problem, goals, constraints and prior rejected options; do not reopen settled choices without new reasons.
2. Offer genuinely distinct viable approaches: simpler workflow or AI assistance, existing tools, and custom development when relevant.
3. Compare user value, recurring human effort, privacy, portability, operational burden, reversibility and cost.
4. Recommend the smallest evidence-based approach. Describe assumptions, risks and how to test them.
5. Document the chosen approach, alternatives and unresolved decisions in the project's own working format when authorized.

**Done:** There is a justified choice or a specific test capable of resolving the remaining uncertainty. Choosing no application is a valid outcome.
