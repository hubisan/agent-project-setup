# agent-project-setup

Portable, provider-independent AI workflows for projects and knowledge bases.

A project can start as research or a plan and does **not** need to become a software application. The setup guides discovery, decisions, planning, work, reviews and handoffs with optional, phase-specific agent skills. It works with existing Markdown or Org files and Git; `coding-agent-setup` is an independent, optional addition if software development becomes necessary.

**Status:** early implementation. See the upcoming first implementation PR for the phase navigator, adoption instructions and testable example. This repository contains generic setup material only—never personal or confidential project data.
