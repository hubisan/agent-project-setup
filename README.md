# agent-project-setup

![APS project icon](assets/aps-icon.webp)

Provider-independent AI guidance for knowledge bases, planning, research and other projects. A project does not need to become a software application.

**Core principle:** **Decide -> Try -> Adjust.** Make safe, reversible choices, try the smallest useful next step, and adapt to actual results rather than over-questioning. See [phase navigation](docs/phases.md) for boundaries.

## Entry points

- [Phase navigation](docs/phases.md) — select a workflow based on current need
- [Skill catalog and quality gates](docs/skills.md) — phase-specific and cross-cutting **candidates**, reviewed and developed **one by one**
- [Session handoffs](.agents/skills/aps-handoff/SKILL.md) — portable GitHub-Issue handoff prototype with a Markdown fallback (pending pilot)
- [Architecture and rollout](docs/architecture.md) — optional memento and coding setup
- [Approved design baseline v2](docs/spec-v2/README.md) — full specification, 121 decisions and 52 acceptance scenarios in Org and Markdown
- [Implementation tickets](https://github.com/hubisan/agent-project-setup/issues) — roadmap, blockers and acceptance

**Status:** design baseline, six-phase workflow and candidate skill map exist. **No project skills are currently approved for installation.** The six early SKILL.md drafts were withdrawn from active discovery in favour of separate reviews and tests; see [#11](https://github.com/hubisan/agent-project-setup/issues/11). The adoption installer and real user-led menu-planner pilot have not been validated.

AIHero supplies design ideas only; this repo does not copy, vendor or install AIHero skills. `coding-agent-setup` is a separately adoptable option only when software development is needed. Personal memento integration is optional and never a requirement of an independent project.

**Language policy:** write setup documentation and agent instructions in English. Converse in the user's chosen language and preserve each project's existing content language and terminology; never translate project content without a request. The original German specification remains the historical baseline.

Repository data is public; do not add personal or confidential project content.
