These six files are imported verbatim as a **historical design baseline**, including their original publication-status wording. Their stated “not yet implemented/published” status described the point in time when the documents were authored; it is not the current implementation status.

The **current execution plan** is maintained in [GitHub issues #2–#10](https://github.com/hubisan/agent-project-setup/issues) and the actual repo instructions. Implementation details can evolve through reviewed changes without silently rewriting settled user decisions.

When updating the spec, choose one authoritative editing format and generate the other; do not maintain divergent copies. Read only relevant sections during a task. In particular, load the decision register only when a historical choice is disputed or needs tracing.

The general project core is independent of memento. The optional memento features remain future tickets. AIHero contributes conceptual inspiration only: no AIHero skills are copied or installed.
